3.1 Absen Masuk

1

Buka tab Absensi

Tab Absensi otomatis terbuka setelah login. Lihat peta lokasi PKL dan posisi Anda saat ini.

2

Pastikan berada di area PKL

Posisi Anda (titik biru) harus berada dalam lingkaran geofence (radius 350m dari lokasi PKL). Status GPS tampil di atas peta.

✓ Dalam Radius PKL (125m) ✗ Luar Radius PKL (890m) ← masih bisa absen, status "Luar Radius"
3

Klik [ABSEN MASUK]

Modal kamera terbuka. Arahkan ke wajah Anda untuk foto selfie.

7. FAQ & Troubleshooting

MasalahSolusi
Buka link langsung masuk ke akunLogout dulu, atau hapus cache browser. Jangan centang "Ingat Saya" jika HP dipakai bersama.
Absen tidak bisa — GPS tidak akuratTunggu GPS stabil (ikon GPS hijau). Aktifkan mode akurasi tinggi di pengaturan HP.
Peta tidak muncul di cetak lengkapPastikan koneksi internet aktif. Tile OSM membutuhkan internet untuk load gambar peta.
Cetak laporan lama / freezeFilter per guru terlebih dahulu. Jangan cetak semua 300+ siswa sekaligus.
Titik GPS siswa di peta salahAdmin edit lokasi PKL siswa → sistem geocode ulang via Nominatim.
Import CSV gagalCek format CSV: 9 kolom, role harus "siswa" atau "guru", username unik.
Koordinat PKL semua sama (SMKN9)Tunggu batch geocoding selesai (1.2 detik/lokasi). Atau admin jalankan script geocode_live.ps1.
Tidak bisa loginCek username/password. Hubungi admin untuk reset password.
Notifikasi tidak terbacaGanti ke Mode Malam (🌙) di pojok kanan atas.
