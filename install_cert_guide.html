📜 Install Certificate SSL SIGAP

Diperlukan agar APK dan browser dapat berkomunikasi dengan server SIGAP secara aman.

⚠️ Lakukan sekali saja per device. Setelah install, semua fitur sync akan berjalan normal.
⬇️ Download Certificate SIGAP

Langkah 1 — Download

Tap tombol di atas untuk download file sigap_cert.crt

Langkah 2 — Install di Android

1. Buka Pengaturan HP

2. Cari "Keamanan" atau "Security"

3. Pilih "Enkripsi & Kredensial" atau "Credential Storage"

4. Pilih "Install Certificate" → "CA Certificate"

5. Pilih file sigap_cert.crt yang sudah didownload

6. Konfirmasi dengan PIN/password HP

Langkah 3 — Install di Browser Chrome (PC)

1. Buka Chrome → Settings → Privacy and Security

2. Security → Manage Certificates

3. Tab Trusted Root Certification Authorities → Import

4. Pilih file sigap_cert.crt

5. Restart Chrome

Alternatif: Accept di Browser

Buka https://103.153.190.69:8443 di browser

Klik "Advanced" → "Proceed to site (unsafe)"

✅ Browser akan accept certificate untuk sesi ini
