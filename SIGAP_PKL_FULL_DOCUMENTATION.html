1.1 Latar Belakang

Praktik Kerja Lapangan (PKL) merupakan kegiatan wajib bagi siswa SMK yang dilaksanakan di dunia usaha dan industri. Pengawasan kehadiran siswa PKL secara manual menggunakan buku absen konvensional memiliki banyak kelemahan: mudah dimanipulasi, data tidak real-time, dan rekap membutuhkan waktu lama.

SIGAP PKL K9 (Sistem Informasi & Geofencing Absensi PKL) dikembangkan untuk menjawab kebutuhan tersebut dengan memanfaatkan teknologi GPS geofencing, kamera selfie, dan sinkronisasi data real-time berbasis cloud.

1.2 Tujuan Sistem
  • Memastikan kehadiran siswa PKL terverifikasi secara GPS (hanya bisa absen di lokasi PKL yang terdaftar)
  • Memberikan visibilitas real-time kepada guru pembimbing atas kehadiran siswa bimbingannya
  • Mengotomasi rekap laporan bulanan dan ekspor PDF berformat resmi
  • Mengelola pengajuan izin/sakit siswa dengan alur persetujuan digital
  • Tersedia dalam dua platform: Web Browser dan Android APK
1.3 Ruang Lingkup

🔴 Master Admin

Manajemen penuh seluruh user, reset database, persetujuan akun, impor massal CSV, pengaturan kop surat, laporan semua siswa

🔵 Guru Pembimbing

Pantau presensi siswa bimbingan, absen monitoring/pengantaran, persetujuan izin/sakit, cetak laporan per kelompok bimbingan

🟢 Siswa PKL

Absen masuk/pulang dengan GPS+selfie, riwayat kehadiran, pengajuan izin/sakit, pantau status pengajuan

2.4 Arsitektur Aplikasi Mobile (Capacitor)

Aplikasi dikemas menggunakan Capacitor v5 yang mengembungkan WebView Chromium di dalam native Android container. File APK (com.smkn9.sigappkl) memuat aset web (www/) yang identik dengan versi browser.

Khusus untuk SSL self-signed certificate, APK menggunakan SIGAPHttpBridge — custom Java class yang meng-intercept semua fetch() dari JavaScript dan meneruskannya via OkHttp dengan SSL bypass, sekaligus menjadi proxy untuk POST request dengan body JSON.

2.5 Mekanisme Real-time (SSE)

Server-Sent Events (SSE) diimplementasikan di api.php?action=sse_events. PHP melakukan long-polling selama 55 detik per koneksi dengan interval sleep 2 detik, memeriksa:

  1. Tabel attendance untuk record baru → event new_attendance
  2. File flag /tmp/sigap_user_updated.json → event user_updated
  3. File flag /tmp/sigap_perm_updated.json → event perm_updated
📱 Mode APK vs Browser
APK Capacitor tidak dapat menggunakan SSE (EventSource tidak support self-signed SSL pada Android WebView). APK menggunakan polling 8 detik via setInterval untuk sync data. Browser dapat menggunakan SSE penuh jika certificate dipercaya, atau juga fallback ke polling.

✅ Fix Race Condition Persetujuan (v1.8.7+)
Sebelumnya, izin yang sudah disetujui/ditolak bisa muncul kembali beberapa detik kemudian karena syncDataFromServer() mengoverwrite status lokal dengan data server yang belum commit. Fix yang diterapkan:
  • Guard per-item: _approvedPermIds (Map) menyimpan timestamp tiap izin yang diproses — status final tidak bisa mundur ke Pending
  • Logika 4 aturan di merge: jika status lokal sudah Disetujui/Ditolak tapi server masih Pending, status lokal dipertahankan tanpa batas waktu
  • Guard SSE/visibility: event perm_updated, visibilitychange, dan appStateChange tidak memicu sync dalam 60 detik setelah approve
  • Delay 3000ms: sync dipanggil 3 detik setelah server konfirmasi (bukan 500ms) agar DB sempat commit
  • api.php normalize: status di-normalize eksplisit ke Disetujui/Ditolak/Pending (bukan ucfirst yang rentan encoding)

FAQ Teknis
Q: Bagaimana cara tambah lokasi PKL baru?
Tambahkan di dictionary KNOWN_PKL_LOCATIONS di awal js/app.js, atau biarkan sistem menggunakan Nominatim geocoding otomatis dari nama lokasi.
Q: Bagaimana mengubah radius geofencing?
Default 350m. Ubah nilai allowedRadiusMeters di TARGET_LOCATION atau per-user di database field allowed_radius.
Q: Apakah bisa offline?
Ya, dengan batasan. Login offline menggunakan localStorage. Absensi akan gagal submit jika tidak ada koneksi (data tidak dikirim ke server).
Q: Format impor CSV?
Header: role;nama;nomor_induk_nisn_nip;username;password;kelas;sekolah;lokasi_pkl;guru_pembimbing. Download template dari tombol di halaman import.
