Splash Screen & Inisialisasi

Saat pertama kali dibuka, aplikasi menampilkan splash screen dengan logo SIGAP PKL dan animasi loading.

  • Aplikasi dibuka (APK diklik atau URL diakses)
  • Splash screen muncul dengan logo dan animasi
  • Sistem memeriksa sesi yang tersimpan (checkAuthSession)
  • Jika ada sesi valid → langsung ke dashboard
  • Jika tidak ada sesi → tampil halaman login
💡 Splash screen sekaligus memuat data dari server secara background (startup sync)

SISWA
📷
Tempelkan screenshot
Peta Leaflet
dengan marker PKL & posisi siswa
Screenshot: peta dengan titik merah (PKL), lingkaran geofence, dan titik biru (posisi siswa)

Peta & Geofencing GPS

Peta interaktif menampilkan posisi siswa dan lokasi PKL secara realtime.

  • 📍 Marker merah = Lokasi PKL terdaftar
  • 🔵 Titik biru = Posisi siswa saat ini
  • ⭕ Lingkaran = Radius geofence (default 350m)
  • Badge GPS: Dalam Radius (hijau) / Luar Radius Xm (merah)
  • Koordinat PKL otomatis dari database
💡 GPS perlu beberapa detik untuk akurasi optimal. Aktifkan mode akurasi tinggi di HP.

Import CSV Massal

Admin mengupload file CSV untuk mendaftarkan banyak siswa dan guru sekaligus.

Laporan Rekapitulasi

Tabel ringkasan presensi semua siswa dalam satu bulan, dikelompokkan per guru pembimbing.

  • Pilih bulan dari filter
  • Pilih guru pembimbing (atau "Semua")
  • Klik [📋 Cetak Rekap]
  • Tabel berisi: nama, pembimbing, PKL, per tanggal: masuk/pulang/status
  • Dikelompokkan per guru pembimbing (kelompok biru)
  • TTD 3-kolom di akhir dan di halaman grafik

Reset Database

Menghapus semua data siswa, guru, dan log presensi. Hanya akun admin yang dipertahankan.

  • Buka tab Profil & Pengaturan
  • Scroll ke bagian Reset Database
  • Klik [🗑️ Reset Database]
  • Dialog konfirmasi pertama → klik OK
  • Dialog konfirmasi kedua → klik OK untuk lanjutkan
  • Semua data terhapus, dashboard kosong
⚠️ TIDAK BISA DIBATALKAN. Pastikan sudah backup data sebelum reset. Cache koordinat PKL tetap tersimpan untuk keperluan import ulang.
